# Rainy Days

The fictional storefront page for the Rainy Days company selling outdoor jackets

## Description

Fictional storefront page from start page to successful purchase and all pages needed for a purchase (Not functional, purely CSS and HTML). Pages included:

- Index page
- Products
- Product Description
- Cart
- Checkout + Checkout Filled + Card Details (Simulated)
- Purchase Successful
- Placeholder Page
